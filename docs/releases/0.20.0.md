# earthcarekit 0.20.0 (November 10, 2026)

This release enhances scattering ratio processing for ATLID L1 data, adding a (optional) BSR threshold.
Breaking changes where made to the related API.
The code was restructured in a new `scatt_ratio` module.

With regard to plotting, the default styling for marked site/radius/time selections in curtain/swath/line plots has been updated for improved visual consistency.
`SwathFigure` now plots the site radius as a circle when using the site option, providing clearer spatial context.

Additional improvements and bug fixes have been applied across the package.

## Changelog

### Breaking Changes
- Add BSR threshold option to ATLID L1 scattering ratio calulcation and restructure related code in new `scatt_ratio` module
- Ensure constistent marking scheme for time selections and radius across `TimeseriesFigure` classes

### New Features
- Add segment number argument to `geo.shapes.radius()`
- Draw geographic radius on `SwathFigure` plots instead of time-based vlines
- Add array dimension alignment and trimming utilities
- Add AC__CLP_2B reader
- Add combine function for variable tranformers
- Add filepaths result column, csv export, and request limit controls to `ecdownload()`
- Add utilities for filesystem paths

### Bug Fixes
- Improve error message in `Hist2dFigure`
- Correct multipolygon coordinate handling in `ecdownload()`
- Correct file path extraction in `save_plot()`
- Remove artifacts from radius plot in `SwathFigure` caused by dateline or coordinates out of swath bounds
- Prevent `ecdownload` crash on empty MAAP archives
- Copy target coordinates to rebinned X-MET to prevent misalignment
- Clean units sting parser
- Propagate `keepdims` attribute to new `Profile` instances
- Correct start/end coordicate extraction from STAC items

### Maintenance
- Fix `PathLike` typing in `get_product_info()` and related functions
- Ensure constistent marking scheme for time selections and radius across `TimeseriesFigure` classes
- Restructure JAXA depolarization percent-to-ratio conversion

### Documentation
- Update list of supported products

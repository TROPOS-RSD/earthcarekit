# earthcarekit 0.18.3 (August 10, 2026)

This release adds support for the new A-LAY baseline BD (new variable `"tropopause_height"`), implements a workaround fixing a current MAAP orbit number search issue for X-MET and fixes filtering of concatenated frames. 

## Changelog

### New Features
- Add TRIM_INDEX_OFFSET_VAR constant

### Bug Fixes
- Add variable to support new A-LAY baseline BD
- Filtering issues for stacked and concatenated datasets

### Maintenance
- Add release helper script
- Exclude docs folder from ruff formatting

### Documentation
- Restructure documentation and refator generation workflow

### Other Changes
- Fixed `ecdownload()` orbit number search workaround for recent X-MET data
